Configuration and Features

Tune automated behavior and connect real-time events.

Auto-Approve

You can set automation.autoApproveThreshold (e.g., 0.9) in your config.yaml file or the environment variable AUTO_APPROVE_THRESHOLD. If the system is confident enough in its prediction, it will automatically update Firefly III without waiting for your confirmation.

Webhooks

The application can listen for real-time events from Firefly III. If you configure a webhook in Firefly to point here, new transactions can be categorized instantly as they are created.

Note: If you are running in Docker or on a remote server, you may need to replace the IP address with your server's actual IP address with network access.
